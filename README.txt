GD Downgrade (Steam, Windows)

Puts Geometry Dash back on 2.2081 so Geode mods like GD Rewind work again until Geode supports 2.209.

1. Make sure Steam is open and GD is closed.
2. Double-click "Downgrade GD to 2.2081.bat".
3. When Steam's console opens, click the box at the bottom, press Ctrl+V, then Enter.
4. Wait for the window to say Done.

Your save is backed up to your user folder first (C:\Users\yourname). Your mods stay where they are.

When Geode supports the new GD version, double-click "Undo GD downgrade.bat" to update GD again.

If Windows says it protected your PC, click More info, then Run anyway.
